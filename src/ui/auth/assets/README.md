# Google sign-in asset

`google-sign-in-light-icon.png` is an unchanged official pre-approved Google Sign in button asset, downloaded 2026-09-10 from [Google's branding guidelines](https://developers.google.com/identity/branding-guidelines) and its [official asset archive](https://developers.google.com/static/identity/images/signin-assets.zip).

Exact archive entry: `Android + Web/PNG @4x/Light/Theme=Light, Show text=No, Shape=Square, Platform=Android+Web@4x.png`.

The 160×160 PNG includes the standard multicolor G, white background and button border. SHA-256: `2bc2ae8e4c67de66d74bf1deed12cd8f22981270266a487576b671b0b4df361c`.

The archive contains no localized raster buttons. The application uses the officially supported icon-only mode at 40×40 CSS pixels, preserving the asset's aspect ratio and internal padding, inside a 44×44 native Astryx button. Adjacent FR/EN action text and the button's accessible label identify the sign-in action. No font, SVG text, GIS SDK, remote asset request or hand-drawn logo is used. Google's brand usage terms apply to this asset; it is not an application logo or a grant to modify Google's branding.
